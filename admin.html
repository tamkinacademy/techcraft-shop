স্টোরে প্রকাশ করুন

পণ্য যোগ/বদলানোর পর নিচের বাটনে ফাইল ডাউনলোড করে GitHub-এ আপলোড করলেই সবার ফোনে নতুন পণ্য দেখাবে।

  1. ওপরের বাটনে চাপুন → shop-data.js ফাইল ডাউনলোড হবে
  2. GitHub-এ আপনার শপের repo খুলুন → Add file → Upload files
  3. ফাইল ম্যানেজার (Files অ্যাপ) থেকে ওই shop-data.js বাছুন
  4. Commit changes চাপুন। ১–২ মিনিট পর স্টোরে নতুন পণ্য দেখাবে

ফাইলের নাম অবশ্যই shop-data.js থাকতে হবে। (ব্রাউজার নাম বদলালে যেমন "shop-data (1).js" – নাম ঠিক করে নিন)
